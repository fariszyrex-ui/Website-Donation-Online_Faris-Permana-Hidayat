# Website Donasi Online

Website donasi online yang dibuat untuk memenuhi tugas sekolah wlee 🤪✌️.

## Teknologi
- PHP Native
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Fitur
- Login admin
- Dashboard admin
- Kelola campaign
- Kelola donatur
- Transaksi donasi
- Berita
- Upload gambar

## Cara Menjalankan

1. Clone/download repository ini.
2. Masukkan folder project ke `htdocs`.
3. Jalankan Apache dan MySQL melalui XAMPP.
4. Buat database di phpMyAdmin.
5. Import file `database.sql`.
6. Sesuaikan konfigurasi database pada `config/database.php`.
7. Buka project melalui browser.

## Database

File database tersedia di:

`database/database.sql`
